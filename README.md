# StudyPilot

> 别再用“准备”当借口了，你只是缺个推手。

是不是经常这样：脑子里的计划很完美，手边的事情却一拖再拖？

不是你不努力，你只是卡在了“开始”的那一秒。

StudyPilot 不给你打鸡血，只帮你做一件事：**最小启动**。

- **AI 拆解**：把“写论文”变成“先写 50 个字”，让第一步简单到无法拒绝。
- **呼吸调频**：用简短呼吸练习，把焦虑慢慢调成专注。
- **成长档案**：不看结果看行动，记录每一次成功开始。

别在脑子里跑马拉松了。先穿上鞋，走出门。

## 核心功能

- 将任务转为约 3–7 分钟、能真正进入任务的启动单元
- 开始前的呼吸启动仪式
- 学习与自由专注计时
- 本地保存行动与呼吸记录
- 成长档案与行动痕迹

## AI 配置

复制 `.env.example` 为 `.env.local`，再填写任意 OpenAI-compatible 服务的配置。示例默认使用 DeepSeek。

API 密钥仅由服务端 API 路由读取；不要将 `.env.local` 提交到 Git，也不要把密钥放进浏览器代码。

## 运行

```powershell
npm.cmd run dev
npm.cmd run test
npm.cmd run build
```

## 更新记录

### 呼吸练习优化

- 呼吸阶段名称保持单行显示，避免「吸后停顿」「呼后停顿」换行。
- 阶段文字与倒计时数字的层级更平衡，数字仍是视觉重点。
- 增加准备页与「开始呼吸」确认，启动不再突然。
- 增加 3 → 2 → 1 → 开始 的准备倒计时。
- 每个阶段都会倒计时至 0，并在切换前短暂停留。
- 呼吸节奏整体更慢、更自然；呼吸完成后再由用户确认开始行动。
