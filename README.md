## 配置 AI

复制 `.env.example` 为 `.env.local`，填写任意 OpenAI-compatible 服务的配置。默认示例为 DeepSeek。密钥仅由服务端 API 路由读取，绝不能放入浏览器代码或提交到 Git。

## 运行

`npm.cmd run dev` · `npm.cmd run test` · `npm.cmd run build`
